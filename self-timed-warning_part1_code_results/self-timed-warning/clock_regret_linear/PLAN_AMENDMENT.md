# Pre-timing sample-size amendment

8 October 2026, before any new timing-study measurements. The original plan uses eight independent inputs per each of seven sizes. A two-sided exact sign test with eight unanimous signs has minimum p=2/2^8=.0078125; the first Holm threshold for seven tests is .05/7=.007142857. Therefore that design cannot reject even with unanimous results.

Increase independent inputs from8 to12 per size, retaining three repeated timings per input and the other design choices. With12 unanimous signs, p=2/2^12=.00048828125, so correction permits rejection. This amendment is based on test resolution, not observed runtime outcomes; no timing results have been obtained. Retain the original plan and separately hash this amendment. Significance still cannot establish historical novelty or public priority.
