# Novelty audit for the observability pivot

Search date: 8 October 2026. Searches preceded implementation and continued after the public/sealed contract and ratio bounds were implemented. Terms included maintenance informative censoring/identifiability; age replacement partial identification and censoring bounds; preventive maintenance policy evaluation benchmark; logger-induced censoring; counterfactual policy evaluation; censored offline policy evaluation; partial identification beyond overlap; and censoring-sensitivity/infrastructure-management benchmarks. Primary papers, author repositories and publisher pages were used. This is a targeted audit, not a comprehensive systematic review.

## After-implementation attack

The exact bounds reduce to extremizing positive costs and durations for missing outcomes. They are not a new partial-identification estimator. A theorem asserting their algebra is new would fail the mathematical novelty gate. Sealed evaluator labels are not recoverable physical audits. A resource claiming intervention data when it has artificial truncation would be misleading. A resource claiming first ever benchmark of censoring would conflict with Báskay et al. and infrastructure benchmarks.

Potentially distinct artifact: the same fixed maintenance-policy pool and assets, all logger-target pairs, all cost/lead settings, paired complete versus censored outcome-summary views, a truth-free certificate API, constructive incompatible completions and controlled additional-information curves. No exact equivalent artifact was located in the targeted searches. This supports investigating a **benchmark/empirical contribution**, not establishing worldwide priority by absence of search results.

## Decision

The new-method claim is rejected. The paired resource/empirical claim is **B: potentially novel but insufficiently established**. It has an original local implementation and new measured outcomes, but requires stronger operational/sensor-prefix validation and resource-focused external novelty review. This conclusion is deliberately different from claiming YES to a proven genuinely novel scientific method. The user's request to add novelty does not change the evidentiary standard.

Remaining technical distinction to test: whether the paired outcome-summary contract is sufficiently useful beyond existing censoring-sensitivity and partial-observation benchmarks. Run full causal prefix replay including pending alarm deadlines; compare justified survival/censoring estimates; validate on independent intervention logs. If an existing resource already supplies these same paired tasks, release the code as replication/extension rather than claim novelty.
