# Statistical and mechanism validation

8 October 2026. This analysis is specified before this new run, after inspection of the earlier findings. It is **post hoc**, not preregistered. All existing source files and results are protected by hashes; only `method_validation/` and `out/method_validation/` may change.

Question: do the empirical observability effects survive appropriate paired inference, and is the implemented evaluation mechanism different from established worst-case partial identification? These are separate questions. Statistical significance cannot establish scientific priority or a new decision mechanism.

Primary inference uses six engine datasets and Battery leave-one-batch-out (LOBO). Battery CV is a sensitivity analysis because it reuses the same cells. No pooled test treats repeated settings, logger-target pairs, folds or label-release seeds as independent observations. Within each dataset an asset's entire collection of outcomes stays together. Fixed original models/policies are not refitted. Results are conditional on those fitted policies and the assumed independence of test assets within fixed outer splits; dependence from shared training and batch-level effects is not estimated. Battery has only three batches, so cell inference cannot establish generalization across battery batches.

Primary paired contrasts: an asset's observable fraction, averaged equally over all fixed cost/lead settings and the other three targets, for logger 1SE minus each of plain, CAT and CATc. Two-sided exact sign tests discard ties and test the probability of a positive difference among non-tied assets, **not a zero mean**. Holm adjustment covers all 21 primary dataset/contrast tests. The three Battery CV tests form a separate sensitivity family. Report asset counts, ties, direction counts, adjusted p-values, mean differences and 95% percentile bootstrap intervals. No alternative contrasts are selected after seeing p-values.

Bootstrap: 2,000 draws, seed 20261008, resample complete assets with replacement separately within each original outer split; retain all paired settings and methods for each selected asset. Report conditional 95% intervals for observable fractions, mean hidden failure fraction under healthy substitution, true/certified/missed economic gains, and false safe/economic declarations. Task-level summaries give equal weight to the fixed split/setting/pair cells, following the previous report. Asset-level paired contrasts give equal weight to assets. Do not report confidence intervals as future deployment guarantees or confidence intervals for identification bounds. Threshold statistics can be discrete/nonregular; bootstrap intervals are diagnostic, not exact coverage guarantees.

Mechanism test: independently express the missing-outcome cost/use problem as a standard Charnes-Cooper linear program. Reproduce every earlier cap evaluation's endpoints, then compare certification decisions. It is a mathematical reproducibility check, not a superiority hypothesis test. No p-value is appropriate for deterministic equality or algebraic interval containment. The LP is a generic baseline, not an implementation or empirical replication of the distinct smoothness assumptions in Khan et al. (2024).

Literature: revisit primary sources on missing-data partial identification, no-overlap off-policy evaluation, and nonparametric censored maintenance cost bounds. Apply the user's strict novelty gate: different problem, formulation, decision mechanism, nontrivial reproducibility, scientifically material difference and absence of equivalent prior art. Keep benchmark novelty separate from method novelty. Reject unsupported methodological claims even if empirical p-values are small.

Verification: compare point summaries with frozen task outputs, check per-asset split uniqueness and repeated-setting alignment, independently test the LP on small exhaustive completions, test Holm against a known example, verify all protected hashes, and deliver reproducible scripts, tables, report and manifest. Preserve earlier verdicts and outputs.

## Interpretation amendment after first results

The first run showed certification-rate percentile ranges excluding the original point estimate. These threshold statistics are nonregular at ties/boundaries. Therefore their percentile endpoints will be explicitly labeled **resampling sensitivity ranges**, not inferential confidence intervals. Only linear means and paired asset mean contrasts retain nominal conditional bootstrap confidence-interval labels. Keep the same seed, estimands and test family; do not select alternative tests to improve significance. This is an interpretation correction prompted by diagnostics, not preregistration.

An additional, explicitly exploratory sensitivity analysis will collapse each contrast to its original held-out split/batch mean and repeat the sign test using those means. This illustrates the loss of inferential resolution if only outer groups are independent; it does not resolve shared-training dependence or justify random-domain generalization. Battery LOBO has three such groups, each engine dataset five. This analysis was added after the asset-level results were inspected.
