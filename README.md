certificate, sharpness and focus-budget characterization, combined with the
previous complete-family certified solver. Validation favors sequential greedy
over the learned attention proposal. Attention remains optional guidance.

**Historical originality and scientific priority are not established by the
current evidence.** Proof verification and synthetic performance tests do not
establish firstness, prospective maintenance benefit or journal acceptance.
This repository makes the work attributable and inspectable; it does not
convert the provisional novelty verdict into an established originality claim.

## Reproduction and preservation

Use the stage-specific README files and saved environment snapshots. Install
dependencies into a new virtual environment; the local `.venv` is excluded.
Temporary scratch work and bytecode caches are excluded. Research output files
are explicitly included even where the original nested ignore file excludes
them from ordinary future staging.

Git line-ending conversion is disabled for tracked files to preserve the exact
bytes required by the frozen SHA-256 manifests. Run read-only verifiers before
rebuilding experiments; older writeful modules may overwrite protected evidence.

No new license or redistribution rights for third-party materials are asserted
by this repository. Existing provenance and license information remain with
their respective files and datasets.
